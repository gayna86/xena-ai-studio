XENA AI STUDIO – VERSIUNEA 0.1 (prototip Android instalabil)

CE ESTE
Aceasta este prima versiune de prototip, construită ca PWA (aplicație web instalabilă).
Poate fi deschisă pe Android și adăugată pe ecranul principal. Nu este încă un APK nativ.

CE FUNCȚIONEAZĂ
- Navigare între Acasă, Prompt Studio, Personaje, Bibliotecă și Setări.
- Crearea și ștergerea fișelor de personaje.
- Salvarea locală a prompturilor.
- Adăugarea imaginilor de referință pe categorii: față, siluetă, păr, ținută, poziție, decor.
- Export și import backup JSON.
- Interfață adaptată pentru telefon.

CE NU ESTE IMPLEMENTAT ÎNCĂ
- Generarea AI efectivă de imagini.
- Editarea AI efectivă a fotografiilor.
- Sincronizarea cloud între dispozitive.
- Conturi și autentificare.
Aceste funcții necesită alegerea și conectarea unor motoare/servicii compatibile. Gratuitatea nelimitată nu poate fi garantată.

CUM O TESTEZI RAPID
1. Dezarhivează folderul pe calculator.
2. Pentru test local, deschide index.html într-un browser. Funcțiile locale de bază merg, dar instalarea PWA necesită HTTPS sau localhost.
3. Pentru instalare pe Android, publică folderul pe un serviciu static HTTPS (de exemplu GitHub Pages).
4. Deschide adresa HTTPS în Chrome pe Android.
5. Din meniul Chrome alege „Instalează aplicația” sau „Adaugă la ecranul de pornire”.

IMPORTANT
Datele sunt salvate în spațiul local al browserului. Nu șterge datele site-ului înainte de exportarea unui backup. Imaginile sunt limitate la 8 MB fiecare în acest prototip.
Folosește fotografii doar dacă ai dreptul și permisiunea necesare. Pentru persoane reale, păstrează utilizarea respectuoasă și neînșelătoare.

URMĂTORUL PAS
Înainte de publicare, putem testa prototipul și apoi îl putem împacheta ca aplicație Android nativă. Pentru sincronizare cloud vom proiecta separat un backend cu opțiune gratuită și limite explicite.
